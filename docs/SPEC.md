# คำคมออนไลน์ — สเปกโปรเจกต์ (ฉบับร่าง 31 ต.ค. 2569)

## เป้าหมาย
แอปฝึกคำศัพท์ภาษาไทยด้วยเกม **คำคม** (กติกาทางการ EduPLOYS) สำหรับนักเรียนในห้องเรียน
นักเรียนเล่นได้ 2 แบบ: **แข่งกับบอท AI** และ **แข่งกับเพื่อน (2 เครื่อง)**

## กลุ่มผู้ใช้
| บทบาท | ใช้ทำอะไร |
|---|---|
| ครู | สร้างห้อง/ห้องเรียน กำหนดโหมดตรวจคำ ดูสถิติและคำที่นักเรียนเล่น |
| นักเรียน | เข้าเล่นด้วยรหัสนักเรียน เล่นกับบอทหรือเพื่อน |

## แพลตฟอร์ม
- **แท็บเล็ต + คอมพิวเตอร์เท่านั้น** (แนวนอน, ปุ่มใหญ่, min-width 900px)
- ไม่ทำเวอร์ชันมือถือ — จอเล็กเกินสำหรับกระดาน 15×9

## กติกาที่บังคับใช้ (ตามคู่มือ EduPLOYS)
- กระดาน 15 คอลัมน์ × 9 แถว (135 ช่อง) + แถบสระ/วรรณยุกต์
- ช่องพิเศษ 6 แบบ: ×2/×3 คำ · ×2/×3/×4/×5 ตัวอักษร
- เบี้ย 104 ตัวตามตารางทางการ + เบี้ยกระดาษ (สระบน-ล่าง/วรรณยุกต์) ไม่จำกัด
- **ยกคำเก่าออกทุกตา** เหลือเฉพาะคำล่าสุด (ยกเว้นต่อหน้าคำเดิมในแนวเดียว)
- บิงโก 6→40 · 7→50 · 8→70 · 9→90
- เปลี่ยนเบี้ย 1–9 ตัว (ถุงต้องเหลือ ≥9) · ผ่าน · จบเกม 2 กรณี (โบนัส 2 เท่า / หักแต้ม)
- ⚠️ **ไม่ใช่ Scrabble** — ห้ามนำกติกา Scrabble มาใช้
- พจนานุกรม: พจนานุกรมฉบับราชบัณฑิตยสถาน พ.ศ.2554 (36,776 คำสมบูรณ์)

## การตัดสินใจที่ยืนยันแล้ว (31 ต.ค. 2569)
1. **เล่นกับเพื่อน:** ส่ง **ลิงก์เชิญ** ให้อีกฝ่ายกดเข้าห้อง
2. **บอท 3 ระดับ:** ง่าย / ปานกลาง / ยาก
3. **การตรวจคำ:** ครูเลือกตอนสร้างห้อง — (ก) ตรวจอัตโนมัติทันที (ข) ลงก่อนแล้ว Challenge ตามกติกาจริง
4. **สถิติสำหรับครู:** ต้องมี — เห็นคำที่เล่น คะแนน คำที่ผิด (ต้องมีบัญชีนักเรียน)

## สถาปัตยกรรม (เสนอ)
```
แท็บเล็ต/คอม  ──WebSocket──►  Cloudflare Worker + Durable Object (ห้องละ 1 DO)
      │                              │
      │                        D1 (SQLite): users, classes, rooms, moves, results
      └── static assets ──►  Cloudflare Pages
```
- **Server-authoritative**: DO ถือสถานะกระดาน/เบี้ย/ตาเดิน ตรวจการเล่นด้วย rules module เดียวกับ client (กันโกง)
- **บอท** รันใน DO (ใช้ rules ชุดเดียวกัน) — client ไม่ต้องคำนวณ
- **บัญชี:** ครูสร้างห้องเรียน + บัญชีนักเรียน (รหัสนักเรียน/รหัสผ่านสั้น) ไม่ต้องใช้อีเมล
- **ลิงก์เชิญ:** `https://<domain>/room/<code>` — คนที่สองกดเข้าได้ทันที

## ค่าใช้จ่าย
| ส่วน | แผน | ค่าใช้จ่าย |
|---|---|---|
| Pages + D1 | Free | 0 |
| Workers + Durable Objects | Workers Paid | **~$5/เดือน** |

> Durable Objects ไม่อยู่ใน free tier — จำเป็นต้องอัปเกรดถ้าต้องการเล่น 2 เครื่องแบบเรียลไทม์
