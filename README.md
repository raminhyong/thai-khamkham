# คำคม · เกมต่อคำภาษาไทย

เกม "คำคม" ตามกติกาทางการ EduPLOYS — กระดาน **15 คอลัมน์ × 9 แถว (135 ช่อง)**
เล่น 2 คนผลัดกันบนมือถือเครื่องเดียว ตรวจคำอัตโนมัติกับ**พจนานุกรมฉบับราชบัณฑิตยสถาน พ.ศ.2554** (36,776 คำสมบูรณ์)

> **สถานะ:** เล่นได้ตามกติกาหลัก — ยังไม่มีบอท · ยังไม่มี Challenge/โหมด 2v2 · ยังไม่มีจับเวลา 25 นาที/คน

## เล่นเลย
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ (ต้องมี เพราะโหลด `data/dict.json` ด้วย `fetch`)

```bash
python3 -m http.server 8765     # แล้วเปิด http://127.0.0.1:8765
```

## กติกาที่ใช้จริงในเวอร์ชันนี้

| ข้อ | กติกา |
|---|---|
| กระดาน | **15×9 = 135 ช่อง** · ช่องพิเศษ 6 แบบ (×2/×3 คำ · ×2/×3/×4/×5 ตัวอักษร) · ดาวกลาง = ×2 คำ |
| เบี้ยในมือ | 9 ตัว/คน · ถุงรวม **104 ตัว** ตามตารางทางการ (รวมเบี้ยคู่ ฆ/ซ ฌ/ษ ฤ/ฎ ฐ/ฑ ฒ/ณ ศ/ฤ ฬ/ญ ฮ/ฦ) |
| ตาแรก | ต้องผ่านช่องดาวกลาง |
| ตาถัดไป | ต้องต่อกับเบี้ยเดิม · เบี้ยใหม่ต้องเรียงติดกันในแนวเดียว |
| สระ/วรรณยุกต์ | เลือกจากแป้นแล้วเกาะช่องที่วางล่าสุด · สระนำหน้า (เ แ โ ใ ไ) จัดอัตโนมัติ |
| ตรวจคำ | ทุกคำที่เกิด (คำหลัก + คำตัดขวาง) ต้องอยู่ในพจนานุกรม |
| คะแนน | ค่าตัวอักษร × ตัวคูณตัวอักษร แล้ว × ตัวคูณคำ |
| บิงโก | 6 ตัว +40 · 7 ตัว +50 · 8 ตัว +70 · 9 ตัว +90 |
| ยกคำเก่า | **ยกคำเดิมออกทุกตา เหลือเฉพาะคำล่าสุด** (ต่อหน้าคำเดิมในแนวเดียวไม่ต้องยก) |
| เปลี่ยนเบี้ย | 1–9 ตัว เสียตา · เปลี่ยนไม่ได้ถ้าในถุงเหลือ < 9 ตัว |
| จบเกม | ถุงหมด + เบี้ยหมดมือ → ได้ 2 เท่าของแต้มเบี้ยคู่ต่อสู้ · ถุงหมด + ผ่านครบ 6 ครั้ง → หักแต้มเบี้ยในมือตัวเอง |

## แหล่งข้อมูล
- **พจนานุกรม (หลัก):** `dictionary.orst.go.th` — พจนานุกรมฉบับราชบัณฑิตยสถาน พ.ศ.2554
  ดึงทั้งคลัง **39,184 รายการ** (46 ตัวอักษรตั้งต้น) → กรองเหลือ **36,776 คำสมบูรณ์**
- **กฎการกรอง (ผู้ใช้กำหนด 31 ต.ค. 2569):** ต้องเป็นคำไทยล้วน ไม่มี `-` (เช่น `กฐิน-`) · ไม่มีเว้นวรรค (วลี/สำนวน) · ไม่มี `ๆ ฯ ( ) . , /` · ยาว 2–15 ตัวอักษร
- **คำร่วมสมัยที่ ORST ยังไม่มี** (มือถือ/อีเมล/แชท) → เพิ่มเองได้ที่ `data/orst/allowlist.txt`
- **ค่าตัวอักษร:** คำนวณจากความถี่ในรายการคำ (1–4 คะแนน) — **ไม่ใช่ตารางคะแนนทางการของเกมคำคม**
- **จำนวนเบี้ย:** สัดส่วนตามความถี่ รวม 100 ตัว

## โครงสร้าง
```
index.html          หน้าเกม
css/style.css       ธีมพาสเทล/glass
js/rules.mjs        ตรรกะล้วน (ตรวจคำ คิดคะแนน) — เทสต์ได้ด้วย Node
js/main.js          UI
data/dict.json      พจนานุกรม + ค่าเบี้ย (858 KB)
tools/orst_count.py     นับจำนวนรายการต่อตัวอักษร
tools/orst_crawl.py     ดึงคลัง ORST (resume ได้) → data/orst/raw.jsonl
tools/build_orst_dict.py กรองคำสมบูรณ์ → data/orst/words.json
tools/build_game_dict.py สร้าง data/dict.json (ORST + allowlist)
tests/logic.test.mjs  เทสต์ 7 เคส
```

```bash
node tests/logic.test.mjs     # ✅ ผ่านทั้ง 7 เทสต์
```

## ข้อจำกัดที่ยังไม่มี
- ไม่มีบอท (ต้องเล่น 2 คน)
- ไม่มีระบบห้อง/เล่นออนไลน์หลายเครื่อง
- ไม่มีการเซฟเกม · ไม่มีเสียง
- พจนานุกรมเป็นรายการคำทั่วไป ไม่ได้กลั่นกรองตามพจนานุกรมฉบับราชบัณฑิตยสถาน
